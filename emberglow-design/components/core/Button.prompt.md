One pill-shaped button; Cinnabar `primary` is reserved for the single main action on a screen.

```jsx
<Button variant="primary" size="lg" fullWidth>Begin quest</Button>
<Button variant="outline" fullWidth>Abandon quest</Button>
```

Variants: `primary` (Cinnabar, ember glow on hover), `secondary` (bone-wash fill), `ghost`, `outline` (Aegean border — used for destructive-ish actions like Abandon). Sizes sm/md/lg; press scales to 0.98.
