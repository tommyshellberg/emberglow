Quest presence state machine

The pure-TS core of Approach B. Every pass/fail decision lives here; platform events are just inputs. Dashed = terminal states.

Inputs (normalized platform signals)

APP_ACTIVE / APP_BACKGROUND — from React Native AppState (both platforms)
SCREEN_LOCKED — iOS: protectedDataWillBecomeUnavailable (new native code) · Android: existing ACTION_SCREEN_OFF
SCREEN_UNLOCKED — iOS: protectedDataDidBecomeAvailable · Android: existing ACTION_USER_PRESENT
GRACE_DEADLINE / TIMER_COMPLETE — internal clock ticks fed by the runtime, injectable in tests
